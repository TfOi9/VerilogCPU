# Store 驻留证明优化验收（2026-10-15）

本轮在 `3f0636c` 基线上加入按 Cache set 索引、按 way 保存完整地址身份的驻留目录。选定 FE2/BE2、256 项目录后，六程序 IPC 几何平均由 **0.721017** 提高到 **0.731136（+1.40%）**；官方估计面积 **33,593.58 µm²**、频率 **318.61 MHz**。IPC×估计频率提高 **4.50%**，面积增加 **23.16%**，剩余面积约 2,406.42 µm²。

最高档要求同一配置 IPC≥1.0985、面积≤36,000 µm²、频率≥300 MHz。本方案满足面积和频率，IPC仍需提高 **50.25%**。没有证明最高档已经达到。

## 先验证后端扩宽

先用实现目录前的精确源码冻结 FE2/BE4，跑完25项官方程序并直接运行原版官方综合流程。IPC为 **0.753696（+4.53%）**，面积 **30,180.33 µm²**，频率 **181.21 MHz**。频率不满足300 MHz，因此未采用BE4，也没有把它的IPC与BE2的频率拼接。

## 目录选择与收益来源

小容量目录仍有覆盖损失。普通索引的32/64/128项分别带来−0.243% / +0.453% / +0.854%的均值变化；折叠Cache set高位的试验对应−0.708% / +0.467% / +0.844%，没有稳定优于简单索引，因此保留普通索引并补测256项。小容量和折叠试验只有周期数据，没有各自的PPA；正式PPA只覆盖BE4基线与最终选定配置。

256项目录在16 KiB、512 set、两路Cache中保存10,752位元数据，增加了实际面积。内部结构、失效规则和接线见[目录设计](store-residency-directory.md)。它复用原有不可失败握手、已提交写所有权、标签化返回与Load转发；Cache三周期无阻塞命中契约保持不变。

rsort的28,682笔普通RAM Store中，提前退休数量由19,515增至24,314；缺少证明的数量由9,151降至4,337。其队首Store已请求而等待完成的周期由50,787降至35,156。阶段计数反映优化后的调度与重叠关系，不能直接相加作为预测收益。

| 程序 | 基线周期 | 选定周期 | IPC变化 |
| --- | ---: | ---: | ---: |
| median | 13,357 | 13,357 | +0.000% |
| multiply | 19,934 | 19,934 | +0.000% |
| qsort | 198,361 | 198,365 | -0.002% |
| rsort | 203,472 | 187,842 | +8.321% |
| towers | 7,831 | 7,802 | +0.372% |
| vvadd | 8,361 | 8,361 | +0.000% |

qsort增加4周期，属于明确记录的小幅回退，不能写成六项全部改善。median、multiply和vvadd周期不变，收益主要来自rsort和towers。25项官方程序均通过架构结果检查，不能将六项性能改善推广到其他程序的运行时间。

## 通用机制对照

Store环先写入并驻留32/64/96条独立数据行，再重复访问；没有硬件PC、程序名称或测试地址特判。独立RV32解释器给出架构结果与动态指令数，观测仿真核对退休数，正式与观测仿真的周期逐项一致。

| 驻留行数 | 基线周期 | 选定周期 | IPC变化 |
| --- | ---: | ---: | ---: |
| 32 | 33,044 | 13,685 | +141.46% |
| 64 | 65,823 | 27,389 | +140.33% |
| 96 | 98,614 | 41,093 | +139.98% |

这些测试证明驻留证明覆盖率能解除热Store的响应等待，不是六项官方程序的收益承诺。单行热Store上的本地完成仲裁串行点没有在本轮修改。

## 正确性与溯源

最终源码完成以下检查，验收脚本核对实际退出状态和SHA256：

- `make unit`、`make lint`，包括实际512 set/两路/256项目录的严格lint。
- 71组目录定向/随机/所有权与负向参数检查，统计到11,184次响应核对；包括1/2/3/4 way、单项与截断目录、高地址、别名、错误refill/写回、反压、部分字节写、已提交写跨回滚和flush。
- 28组HUM检查、7,168次返回所有权检查。
- 81组宽度/容量配置的324项静态检查，9组代表配置的27条逐退休差分轨迹与243次程序运行；其中225次官方程序、18次本地smoke。
- 精确选定配置的25项官方程序、全六项IPC及正式/观测周期一致性检查。
- 未修改的课程官方PPA流程：Yosys 0.63、OpenSTA、ASAP7、FakeRAM、2 ns时钟、默认ABC驱动和5 fF负载。库、参数、源码和产物均由快照审计。

原始日志、冻结源码、构建命令和失败记录在 `build/store-directory-20261015/`。首次定向测试的覆盖计数错误已修正；折叠试验发现并修正refill地址位选错误，相关失败源码保留，修复后的折叠方案仍因收益不足而未采用。中止的筛选不参与验收。本轮修改限于D-Cache目录、顶层参数、相关测试与文档；SORA和既有未提交计划文件未修改。
