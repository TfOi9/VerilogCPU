# 256 项 Store 驻留目录（2026-10-17）

在恢复宽度 7 和提前重定向版本上，把 `student_top.STORE_DIRECTORY_ENTRIES` 从 128 改为 256。目录仍按 Cache set 索引、按 way 保存完整行身份；扩大容量只增加驻留证明覆盖率，不改变 Store 数据路径、Load 转发、精确异常或 MMIO 规则。

## 性能

固定 FE=2、BE=2、PRF64、ROB32、D-Cache 16 KiB 两路、I-Cache 1 KiB 单路、外存延迟 10。

| 程序 | 128 项目录 | 256 项目录 | IPC 变化 |
| --- | ---: | ---: | ---: |
| median | 11,942 | 11,942 | 0 |
| multiply | 18,762 | 18,762 | 0 |
| qsort | 183,966 | 183,975 | -0.005% |
| rsort | 183,966 | 178,675 | +2.96% |
| towers | 7,720 | 7,720 | 0 |
| vvadd | 5,923 | 5,923 | 0 |
| **几何平均** | **0.812045** | **0.815229** | **+0.39%** |

收益主要来自 rsort 更多 Store 获得驻留证明并提前退休；qsort 的 9 周期变化属于调度噪声，记录为轻微回退。其余四项周期不变。

## 面积与频率

同一官方 ASAP7/FakeRAM/OpenSTA `opt` 流程、2 ns 目标：

| 指标 | 128 项（恢复 7） | 256 项 | 变化 |
| --- | ---: | ---: | ---: |
| 总面积 (um²) | 31,534.57 | 34,396.56 | +9.08% |
| SRAM (um²) | 6,723.84 | 6,723.84 | 0 |
| 估计频率 (MHz) | 350.81 | 345.01 | -1.65% |
| 最小周期 (ns) | 2.8506 | 2.8984 | +1.68% |

面积增加约 2,862 um²，仍低于最高档 36,000 um² 门槛；估计频率仍高于 300 MHz。相对原始默认配置，累计 IPC 从 0.788517 提升到 **0.815229（+3.39%）**。面积余量约 1,604 um²，后续新增逻辑必须重新核对 PPA。

## 验证

- 官方 25 项程序在 FE=2/BE=2、D16 KiB 两路、恢复宽度 7、256 项目录下全部通过。
- `make unit`、`make lint` 通过。
- 目录别名、way 所有权、refill/写回错误、回滚和 MMIO 语义沿用已有目录与后续确认测试。
- PPA 为理想时钟、无互连寄生的估计值，不是布局布线签核。

原始证据在 `build/store-dir256-current/` 与 `build/ppa-store-dir256-current/`，本轮未修改 SORA，未推送远程。
