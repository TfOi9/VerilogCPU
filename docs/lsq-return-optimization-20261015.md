# Dcache 返回至 LSQ 地址控制链优化

本轮以 `bcd3f31` 为基线，只修改内存 RS 的组合选择和地址生成。官方 25 个程序的周期数全部不变，六项 IPC 几何平均保持 **0.730564**；官方综合和 STA 的估计频率从 **315.66 MHz** 提升至 **340.43 MHz**，总面积增加 **1.19%**。Load 命中三周期和快速返回未增加流水级。

## 实现与接线

原路径从 Dcache 返回 ID 选择 LSQ 在途元数据，经完成网络写回广播，使依赖项在内存 RS 内同周期就绪，再串行比较年龄、选择 base/立即数、执行地址加法，最后更新 LSQ 地址寄存器。

现在每项并行比较相对 ROB head 的年龄，就绪后只需排除更老候选，再通过平衡 OR 树选取完整地址、ROB/LSQ tag 和槽号。年龄采用 `ROB_INDEX_WIDTH` 位环形减法，容量为 2 的幂时等价于原距离函数；同年龄按槽号优先。地址加法在各项内与年龄选择并行，不再接在选取 mux 之后。Store 数据使用相同年龄关系、独立就绪集合和锁定状态。

回压时仍保持原锁定项；recover/flush 时停止输出，选择性回滚继续匹配完整 ROB tag。没有增加接口、状态寄存器或握手级；广播、LSQ 地址/数据连接均保持原接法。详细结构见 [memory_rs.md](memory_rs.md)。

## 官方测量

两侧均使用 FE2/BE2、PRF64、ROB32、RECOVERY4、Icache 1 KiB/1 way、Dcache 16 KiB/2 ways、Store 目录 128 项和后续命中确认。官方仿真外部内存延迟为 10 周期。综合使用未修改的官方框架、Yosys 0.63、ASAP7 RVT TT、OpenSTA，目标周期 2 ns，ABC 驱动单元 `INVx1_ASAP7_75t_R`，输出负载 5 fF。

新增组合面积主要来自并行地址计算；RTL 没有新增寄存器，综合映射后的时序面积微小变化不代表新增流水级。以 `IPC × Fmax` 估算的吞吐增加 7.85%，IPC/面积下降约 1.18%。本轮选择以小幅面积换取频率。

限定两个 `dcache.r_id` 输出到全部 256 个 `core.lsq.address` 数据输入，在官方网表、库和 SDC 上独立进行 STA，最坏到达时间由 **3.113 ns** 降至 **2.823 ns**（**-9.32%**），组合级数由 **88** 降为 **83**。两侧最坏起点均为 `dcache.r_id[1]`，终点分别为 `address[4][8]` 和 `address[4][24]`；比较的是整个起终点集合的最坏路径。全局最坏到达时间由 3.113 ns 降至 2.877 ns，略长于本轮限定路径。

候选的全局关键路径已转移到 `core.lsq.address[0][3] → core.lsq.source_value[28]`，属于 LSQ 的 Store-to-Load 转发数据链；pre-ABC 重放按保留的 DFF 身份关联了官方路径起终点，原始 PPA 输出的哈希保持不变。

## 复现与证据

最终验收全部通过：

- `make unit`、`make lint`，以及独立 HUM/返回归属回归。
- 26 组新旧 RS 对照、156,000 次逐周期输出检查。
- 81 组参数矩阵的 324 项静态检查；九组代表配置的 243 次程序运行和 27 条退休轨迹对照。
- 25 个官方程序；全部周期数与基线一致。
- 64 组 Store 后续确认、71 组目录、28 项 HUM/错误/回压回归，以及 12,550 次返回边界检查。Cache HUM 测试继续断言无争用命中延迟为三周期，LSQ/完成网络测试继续覆盖返回直通。
- 当前 RTL、官方测量快照、单元回归和矩阵输入哈希一致；官方 PPA、程序和诊断日志哈希核验通过。

原始证据保存于 `build/lsq-return-20261015/`，完整输入、结果及日志哈希汇总于 [results-summary.json](../experiments/lsq_return_20261015/results-summary.json)。测量器、指定路径 STA、逐周期对照、完整回归和矩阵命令见 [实验说明](../experiments/lsq_return_20261015/README.md)。

第一次逐周期对照因测试平台遗漏 `ROB_ENTRIES` 覆盖而触发参数检查，日志保留；修正测试平台后 26 组配置、156,000 次输出比较全部通过，无需修改 RTL。第一次路径身份诊断与官方 STA 写报告重叠，其完整性检查拒绝了该诊断，随后在输出稳定后重跑。原有三周期命中断言、返回身份、回滚、错误和回压检查继续运行。最终汇总校验当前 RTL 与官方测量快照及回归输入完全一致。
