# 按年龄排序的并行选择器

`rv32_ranked_select` 已接入正式整数/乘除法保留站和完成写回网络。它以组合逻辑输出最多 `PORTS` 个候选，不增加流水级。

## 内部结构与顺序

每项输入包含 valid、age 和完整 payload。较小 age 优先；age 相同时，较小槽号优先。先排除全部已锁定槽位，再对每个候选并行比较其他有效候选是否更老，用平衡加法树计算名次。未锁定输出端口按自身在未锁定端口中的序号匹配名次。每个输出端口用 one-hot mask 和平衡 OR 树归并槽号与 payload。

锁定端口直接保持原槽位，其他端口不会重复选择该槽。`enable_i=0` 时所有输出无效。调用方负责保证锁定槽位有效，并在握手、恢复或 flush 时维护锁状态。非二次幂项数补零至 `1 << SLOT_WIDTH`；单项配置仍使用至少一位槽号。

比较器规模为 O(ENTRIES²)，该实现以增加并行比较换取较短的选择链，不能据此假设扩大 RS 总有收益。

## 接线

整数和 MDU RS 将相对 ROB head 的距离连接 age，将广播旁路后的操作数、操作码和 tag 打包为 payload；整数 RS 另带 PC 和立即数。输出仍经过原统一发射授权与背压锁定。

完成网络将源槽号相对 one-hot 轮询起点的循环距离连接 age，将结果、tag、控制流与异常一起打包。原来的 ROB ready/accept 区分、轮询更新和缓冲消费规则保持不变。

整数和 MDU RS 的派发容量只统计周期开始时的空闲槽；本拍发射释放的槽下一拍才可分配。这切断 issue-ready 到 dispatch-ready 的组合依赖，满站交接可能增加一拍。无效项 payload 清零仍保留，本轮未进行状态抽象改动。

## 验证

`make optimization-unit` 对21组项数/端口数运行21,000个独立顺序参考随机事务，覆盖同龄、锁定、稀疏输出、补零和单项边界。原组件逐周期差分、全核退休差分继续检查接入后的顺序、旁路和背压语义。集成结果及PPA边界见 [本轮报告](optimization-20261014.md)。
