## 结构、逻辑与接线

`student_top.DCACHE_MSHR_WAITERS` 接至 D-Cache 的 `MSHR_WAITERS`，支持 2、4，组件默认 4、整机选用 2。每个 MSHR 保存行地址、牺牲行、写回状态、读返回行和等待项 FIFO；各等待项保存请求 ID、完整 ROB 标签、字位置及 Store 数据/字节掩码。FIFO 指针宽度为容量的 log2，满时阻止新合并；同槽出队允许同拍入队，计数保持不变。写回数据被桥接接受后，桥接已保存整个牺牲行；读请求此后才可发出。因此同一 MSHR 的牺牲行和回填行复用一个 128 位寄存器。写回反压时不发读，防止回填覆盖尚未接受的脏数据；写回错误时，原 Cache 行仍保留，重试会重新取得牺牲行。普通 Load 出队不再重复写回同一个行值。四个缺失槽仍可同时占用。MSHR 数据字段不再复位：地址和牺牲行由分配写入，等待者由入队写入，返回行由拥有该槽的读响应写入；valid、读写完成标志及 FIFO 计数/指针仍复位。零等待者预取不产生核心响应。

桥接队列保存每笔读的来源和完整 ID，AXI 读返回按原顺序归还，写响应保留独立来源。关闭 HUM 或使用阻塞模式时仍支持单 MSHR。MMIO Store 位于 ROB 头，地址为 `0x80000000`、掩码为 `4'hf`；先禁止新预取并排空 Cache，再交给桥接，等待 AXI B 返回。

Load 值缓冲用两个相邻地址位段异或索引，标签只保存 `MEMORY_BYTES` 可表达的合法 RAM 地址高位；标签与索引共同区分所有合法字地址。完整地址异常判断保留，非法高地址不能因标签缩短而命中。共享地址译码的互斥叶节点通过 OR 树读出标签和数据。

只有成功、存活且完整身份匹配的整字 Load 返回能填充；字节/半字返回不建立整字。Store 地址接受和 Cache 写请求接受时按索引保守失效；普通 RAM 整字 Store 真正退休时建立完整值，部分 Store 退休时失效。较老 Store 依赖、转发优先级、回滚和代际检查保留。命中值沿用 LSQ 的 `data_valid/store_data` 字段，完成经过原有仲裁和反压寄存器。

取指行缓冲使用同步 FakeRAM 保存 128 位行数据，标签和 valid 使用寄存器。读取沿用本地响应 valid/PC；反压时保持读取被持有的行，填入优先于新读取，重定向清除在途本地响应。标签省略可由直接映射索引恢复的地址位，但保留所有其余地址高位；高地址仍可独立命中，不与低地址混淆。标签只在建立 valid 时初始化，复位仅清 valid。该结构位于 L1 之外，不改变 L1 三周期命中契约。

PRF 各项共享写地址比较，多个写口冲突时高编号口优先；互斥数据经 OR 树汇合后写入一次。`initialized` 仍复位，无效项按原契约读零，物理零寄存器保持零。

ROB 只移除分配时必定写入的 payload 复位；busy、generation、complete、控制标志以及未受有效位屏蔽的 `new_phys` 保留复位。D-Cache 只允许低 256 MiB 地址分配行，标签省去固定为零的高四位，重建牺牲地址时补零。valid/dirty/替换状态改为 packed vector 以兼容 Linux Verilator 5.020；dirty 和替换 payload 由 valid 及首次填充保护，无需复位所有无效项。

## 空预取错误仲裁修复

空预取错误完成与 S2 普通命中重叠时，旧逻辑可能拉高响应 valid，却选择空预取的等待者字段，产生错误请求 ID。修复让普通命中等待 MSHR delivery 释放响应所有权。定向测试在旧版复现，修复后通过。

预取只使用空闲入口和未占满的 MSHR，零等待者完成不向核心生成结果；需求合并后成为实际等待者。错误不安装新行，脏牺牲行写回错误保留原行及数据。检查包含空预取错误与普通命中的同拍竞争。

附件给出 320 MiB 内存、零磁盘写入以及单点 100–1000 秒限时范围，未展开各点限时。Linux 验收使用 320 MiB 内存及等量内存加 swap 上限、只读容器、fsize=0、非 root、无网络，并以 strace 确认写操作只面向 stdout/stderr。
