# 分支优化第一步：缩短正确路径供给

本轮在`abedc8b`基线上加入4行取指缓冲，保存64B指令数据，复用已成功取回的行。官方六程序IPC由**0.696471**提高到**0.721017（+3.52%）**。同配置官方综合面积**27,275.78 µm²**、估计频率**309.18 MHz**；相对基线，面积+0.89%、频率−1.45%，IPC乘估计频率提高**2.02%**。最高档IPC1.0985仍未达到，还需提高**52.35%**。

## 定位与选择

先测量而未增加分支优先级。基线qsort共观察到43,846次条件分支发射，43,250次在操作数有效的当拍获得发射，其余596次等待一拍；该计数包含推测路径。重定向到目标指令进入Fetch Queue通常需要5拍，分派通常需要6拍，因而优先缩短前端重新供给。

| 同配置周期候选 | 六程序IPC | 相对基线 |
| --- | ---: | ---: |
| 关闭行缓冲 | 0.696471 | — |
| 2行缓冲 | 0.701124 | +0.67% |
| 4行缓冲（采用） | 0.721017 | +3.52% |

初稿1行候选IPC为0.698043，但未锁定已呈现的I-Cache反压请求，仅作为保留的筛选记录，不计入最终候选验收。精确位宽与请求锁定修正后，基线、2行、4行在独立目录重新测量。

| qsort重启统计 | 基线平均拍数 | 4行缓冲平均拍数 |
| --- | ---: | ---: |
| redirect到目标入队 | 5.0155 | 2.2221 |
| redirect到目标分派 | 6.0334 | 3.6643 |
| redirect到目标退休 | 11.7382 | 9.4786 |

每次redirect重新开始统计，目标退休使用完整ROB标签；再次被重定向的样本单列为superseded。优化改变了推测路径与样本数量，表格不是逐事件配对，不应把平均差直接乘误预测次数作为理论收益。分支方向表和训练时机没有修改，本轮也不声称提高了退休预测准确率。

## 结构、接线与边界

行缓冲为直接映射的4项valid/完整28位行标签/128位数据表，仅成功接受的I-Cache响应可以填入。下一PC查询行缓冲与原BTB/BHT；当请求跟踪为空时，命中行装入本地响应寄存器，下一周期进入原有预译码、预测校正和Fetch Queue。只有最后一笔本地响应被消费时，才允许连续交接本地请求。存在真实I-Cache在途请求时不插入本地响应，已呈现但反压的真实请求保持有效及PC稳定。

redirect和内部预测校正清除本地响应与在途跟踪，保留已成功取回的行；reset清空缓冲。错误行不缓存，行内偏移不越过16B边界，JAL与条件分支仍按第一个预测taken截断。预测器变化时重新校正，未对齐预测仍降级为顺序路径。保持既有I-Cache三周期命中契约和指令一致性边界。设计与接线详见[取指设计](fetch.md)。

## 官方测量

固定FE2/BE2、PRF64、ROB32、恢复4、LSQ8、I1 KiB单路、D16 KiB两路、外存10周期；框架版本固定`302f0cf`。25个官方程序在两份冻结源码上重新运行，全部通过，且本轮没有周期回退。综合使用原始官方脚本、Yosys0.63、OpenSTA、ASAP7、2.0 ns目标、ABC默认驱动和5.0 fF负载。基线PPA复用上轮已验收的相同RTL，并审核源码、脚本、库及原始产物哈希。

微基准的结果和动态指令数由独立架构解释器验证，证明一般分支序列也可受益，不能替代官方六程序IPC。频率属于官方理想时钟、无寄生参数和FakeRAM模型下的综合估计，未做布局布线或hold签核。

## 验证状态与证据

完整资格回归已通过：25项官方程序的前后对照；81组参数的324项静态检查；九组代表配置的27条随机退休差分和243次程序运行（225官方、18本地smoke）；完整`make unit`与`make lint`；28项HUM和7,168项返回所有权检查。新增行缓冲测试覆盖27组配置，共3,672项检查，并包含关闭缓冲负对照与非法容量拒绝。原取指接口和真实I-Cache集成测试继续通过。以上属于完整项目回归，不是形式化穷尽证明。

首次Verilator检查因整数索引的未使用高位失败，修正为派生的精确宽度后重跑通过，原失败日志保留。原始证据在`build/branch-restart-20261015/`，命令、timeout和冻结规则见[实验README](../experiments/branch_restart_20261015/README.md)，最终结果见[验收摘要](../experiments/branch_restart_20261015/results-summary.json)。审核确认最终RTL与测量快照逐字节一致，107项资格输入和原始证据哈希均已保留。本轮不修改SORA，不合入其他未提交研究文件，不推送远程。
